# Leone Holiday House Website

This folder contains the complete, static website for Leone Holiday House. 

## How to View
Simply double-click on `index.html` to open the website in your browser. No installation or terminal commands are required.

## Editing Content
- **Text**: Open `index.html` in any text editor (Notepad, TextEdit, VS Code) to change text. Look for the white text between tags like `<h2>...</h2>` or `<p>...</p>`.
- **Images**: Replace image URLs in `index.html` or background images in `styles.css`.
- **Colors**: Edit the variables at the top of `styles.css` (e.g., `--color-gold`).

## Deployment
To publish this website online:
1. Upload all files (`index.html`, `styles.css`, `script.js`) to any static hosting provider.
2. Recommended free options: Netlify Drop, GitHub Pages, or any standard web host (via FTP).
